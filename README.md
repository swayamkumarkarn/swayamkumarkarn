## 🏗️ Things I've Built

### 🤖 AI-Powered Fundraising Platform
End-to-end systems for an AI-driven fundraising platform, including nonprofit discovery, donor intelligence, intelligent search, document processing, AI knowledge bases, and LLM-powered workflows.

**Stack:** `Python` `Node.js` `FastAPI` `Azure OpenAI` `Gemini` `AWS` `Azure SQL` `DynamoDB`

### 🌎 Large-Scale Nonprofit Data Platform
Data pipelines and infrastructure for a nonprofit repository spanning **millions of records across multiple countries** — large-scale ingestion, cleaning & transformation, ETL, search optimization, DynamoDB modeling, and SQL performance tuning.

**Stack:** `Python` `AWS` `DynamoDB` `Azure SQL` `ETL`

### ⚡ Event-Driven Architecture
Asynchronous systems built around `EventBridge → SQS → Lambda → Database`, decoupling services, offloading background processing, and improving system scalability.

### 🖥️ Remote Mouse
A cross-computer remote mouse system for controlling another machine over LAN — real-time movement, click & double-click, scrolling, device discovery, WebSocket communication, server/client modes, global keyboard shortcuts, and an Electron desktop app.

**Stack:** `Electron` `Node.js` `WebSocket` `PowerShell` `RobotJS`

### 🏛️ Citizen & Government Platforms
Production systems for citizen registration, payment gateways, OTP authentication, admin dashboards, and analytics at large user traffic scale.

**Stack:** `Next.js` `Node.js` `Razorpay` `GCP` `MSG91`
